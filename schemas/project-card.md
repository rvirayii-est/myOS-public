# Project card schema (`projects/<id>.md`)

Frontmatter (routing facts, single home):
`type: project-card`, `id`, `name`, `engagement`, `aliases: []`, `repo` (absolute path or UNVERIFIED),
`repo_subpaths: []` (when several cards share one repo), `repo_confidence` (verified-path | inferred | ambiguous),
`github` (owner/repo or UNVERIFIED), `vault_folder`, `vault_hub` (vault-relative), `status_claim`,
`status_source` (where the claim came from and when), `created`, `updated`, `last_verified`, `tags`,
optional `test: "true"`.

Body:
- Human-owned sections: Pointers, Status, Known next actions (historical, with source), Evidence links.
- Generated blocks (never hand-edit; regenerated by the CLI):
  - `<!-- myos:live:begin/end -->` - `myos verify` / `myos save`: read-only git evidence + timestamp.
  - `<!-- myos:handoff:begin/end -->` - `myos save`: latest summary, next actions, blockers, approvals, tests.
  - `<!-- myos:sessions:begin/end -->` - `myos save`: links to the 10 newest session records.

Rules: the card points to evidence and never copies histories. Unknown = `UNVERIFIED`.
